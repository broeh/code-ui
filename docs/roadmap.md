# Roadmap

Track the inherited GTK/GLib audit warnings in `SECURITY.md` and adopt a compatible upstream fix when available.

The first milestone is a dependable Linux alpha with clear setup, portable CLI configuration, private local storage, tests and reproducible release artifacts.

After feedback:

- Broaden tested Linux distributions and CLI versions.
- Improve compatibility reporting and reduce version-sensitive adapter switches.
- Add full-text conversation search and a Git changes view.
- Improve native-history synchronization and terminal continuation actions.
- Consider image attachments, usage/rate-limit information and an updater.
- Assess macOS and Windows support after process and desktop integration work.

These are directions, not commitments or release dates. Cloud synchronization and team features are outside the current scope.
